# Security

Family Trivia holds families' own words, so a hole in it is a hole in
someone's family. Thank you for looking.

## Reporting a vulnerability

Please report it privately, through
[GitHub's private vulnerability reporting](https://github.com/yeahthisisrob/family-trivia/security/advisories/new),
not in a public issue or pull request. Include what you found, how to
reproduce it, and what it lets someone see or do.

You'll hear back within a week. Once it's fixed, the advisory is published
and you're credited, unless you'd rather not be.

## What's in scope

The code in this repository: the API, the web app, the infrastructure
definitions, and anything that could expose one family's data to someone
outside it. Deployments run by other people are theirs to secure.

## Supported versions

Only the latest release on `main` gets fixes.
